# 更新日志

## 2.0.0

设置界面、摸鱼机制、动作与表情的合成方式都动过一轮，所以是 2.0.0。**升级后建议看一眼
下面的「语义变化」** —— 有三条是行为真的变了，不是修 bug。

### 设置界面重做

- 设置区改成**卡片式**：一组一张卡，卡片里是「行」，行里是药丸按钮 / 权重条 / 数值。
  视觉重量跟着信息重量走（抽中概率是主角，原始权重收成行尾的小旋钮）。
- 滑杆重做：3px 细轨道 + 12px 小圆钮，已拖过的一段用强调色填满。
- **槽位和候选都能增删**：`＋ 名字` 是虚线药丸、`＋ 槽位` 是实线药丸，条目行尾有 `×`。
  宠物给的那套只是**建议**，你加进来的运行时真的会抽到。
- **相位改成池子**：每个会话相位下面是"槽位 → 条目表"，和摸鱼同一套机制。
- **关系能增删**：条目下面能看到两种关系，也能自己加、自己删
  - **同时** `pairs`：选了它就一起点亮（喵喵手 → 贴纸 = 猫猫）
  - **前提** `requires`：必须先处于那个状态（挤番茄酱 → 左手 = 蛋包饭）

### 摸鱼与相位

- **默认值按作者自己调好的那套烘进 `pet.json`**：情绪（默认 20 / 开心兴奋 5 / 调皮 5 /
  闭眼口水 1）、脸红（默认 10 / 脸红 1）、右手（默认 1 / 掏出手机 4 / 比耶 4 / 喵喵手 1 /
  挤番茄酱 1）、眼部（默认 10 / 爱心眼 1）、自拍（默认 1 / 自拍 1）。**你自己的存档永远
  优先**，所以升级不会覆盖你调过的东西。
- **摸鱼默认盯哪几个槽位改成宠物自己声明**（`pet.json` 的 `live2d.fidgetSlots`）——
  这只宠物把「自拍」也放进了池子（带着「前提：右手 = 掏出手机」）。以前那六个是写死在
  代码里的。
- **每个池子每次都重掷**（不是"这次只动一两个"）；权重就是"多久动一次"。
- **「默认」＝回到默认**（把这个槽位清空）：`默认 10 : 脸红 1` = 大约每 11 次摸鱼脸红
  一次、其余回到没有。想让某个槽位完全不动，把它的条目删光或权重归 0。
- 摸鱼抽签**在应用前会重查一遍前提**：同一轮里右手被掷成比耶之后，被抽中的自拍不会
  再播（以前会出现"先比耶、再拍照"）。
- **相位列表一开始就列出全部相位**（不再是"空列表 + 点添加才看到默认值"）：每行显示的是
  **有效池子**（你改过就用你的，没改过就用宠物默认），行头标「默认 / 已改过」，
  只有改过的行才有 `×`（= 恢复默认）。**覆盖只在真的编辑时才落盘** —— "看一眼"不会留下
  痕迹，以后宠物更新了默认值你照样吃得到。

### 动作与表情

- **自拍独立成槽**（自拍 / 快速自拍），不再是右手的选项。
- **氛围三个独立**（情绪花花 / 心跳 / 冒爱心）：它们写的是互不相干的参数，以前挤在一个
  槽位里互相顶掉，现在可以同时开。
- **多个动作槽位的姿势可以共存**：右手拿着手机的同时，嘴部吹泡泡糖。
- **最后一个动作槽位说了算**：右手拿着手机时点吹泡泡糖，以前会被静默忽略。
- **选项上的「前提」现在管动作**：给「自拍」加「前提：右手 = 掏出手机」，摸鱼只有手机
  在手时才拍它；手动点选则由插件把前提补上（点自拍会先掏手机）。
- **表情淡入 200ms**：引擎那套表情管理器一次只持有一个表情，多槽位叠加用不了它，
  所以参数是我们自己按帧写的 —— 现在那一层自己补了缓动。

### 界面

- **面板跟随浅色 / 深色主题**（以前是写死的深色，浅色主题下点开就是一块黑）。
- **右键面板去掉「设置」页签**：面板只负责"点一下换个样子"，改数值去 **DSH 设置页 →
  桌宠** 那一节（两处本来共用同一份配置，现在只留一处）。

### 修复

- 配对（同时）做成**不变量**：爱心眼还选中着，冒爱心就不会丢；源头被清掉，配对跟着收。
- **动作定格时爱心不再消失**：爱心的位置参数只有待机循环在驱动，`hold` 的动作定格后
  待机不再跑、这些参数会塌回 0（开关开着却看不见）。现在待机时**逐帧录像**，定格时按
  同样的节奏循环回放 —— 既不塌、也不冻。
- **配对不会"一直出不来"**：以前它是一次性副作用，被清掉一次就再也没人点亮。
- 设置界面里权重输入框压住删除按钮、摸鱼「加槽位」按钮样式不对等一串外观问题。
- DSH 设置页那一节以前没有样式（它渲染在宠物根节点之外，作用域之外）。

### 诊断

新增读口（都挂在 `window.__dshLive2dPet` 上）：`ambientDebug()`、`keptPoseDebug()`、
`effectiveRelations()`、`settingsOverrides()`、`fidgetTally()`、`expressionFade()`。

### 验证

16 个 CDP driver（真实浏览器 + 确定性参数断言，不做像素/哈希比对），全套通过。

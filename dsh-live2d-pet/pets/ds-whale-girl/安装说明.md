# 安装这个宠物

这是一个**可直接使用**的宠物包，而且**随插件包分发** —— 装好插件、重启 `dsh web`，
右下角就会出现鲸鱼娘：宿主半区第一次运行时会把它复制到 `%DSH_HOME%\pets\ds-whale-girl`
（只在目标不存在时复制，不会覆盖你自己改过的那份）。

想手动复制：

```powershell
# Windows
Copy-Item -Recurse -Force dsh-live2d-pet\pets\ds-whale-girl "$env:USERPROFILE\.dsh\pets\"

# macOS / Linux
cp -R dsh-live2d-pet/pets/ds-whale-girl ~/.dsh/pets/
```

然后重启 `dsh web`，右下角就会出现鲸鱼娘。
别忘了先放好 Cubism Core 运行时，见仓库根 README。

## 这个目录是怎么来的

它由 `tools/build-pet.mjs` 从 `model-packs/DS鼠控版/` 生成，做的主要是**把中文文件名
换成 ASCII slug**：DSH 的宠物 manifest 只接受 `[A-Za-z0-9._-]` 的路径片段，而源模型里
的表情文件名是中文，直接拷进去会因为路径校验失败而整个宠物不可用。

想自己改（换动作映射、加表情分类）就改 `pet.json` / `catalog.json`，或者直接重新构建：

```bash
node tools/build-pet.mjs --dest ./dsh-live2d-pet/pets/ds-whale-girl
```

模型与截图都已随仓库分发；**这些图片同样受 CC BY-NC-SA 4.0 约束，不是 MIT**。

这里的图片：

- `banner.png` — 仓库门面横幅（2730×1536），**AI 辅助生成的二创图**：以本插件的实拍截图
  与角色设定为参考重绘，属于 CC BY-NC-SA 4.0 的**改编作品**，使用时同样要署名三位版权所有人、
  不得商用、并以同一协议分发。
- `panel.jpg` — 右键面板实拍：宠物 + 「动作 8 / 装扮 20」两个页签 + 大小滑杆 + 归位（深色主题，
  2 倍分辨率）。由 `tools/browser-test/` 的测试台现拍，随插件改动会过期，更新界面时请重拍。
- `looks.jpg` — 六种造型拼图（默认待机 / 爱心眼 / 星星眼吐舌 / 调皮猫猫手 / 重锤出击 / 挤番茄酱），

- `downscale-fix.png` — 缩小时线条清晰度的前后对比。

这三张（`banner.png` / `panel.jpg` / `looks.jpg`）在 [`../screenshots.json`](../screenshots.json) 里
声明为市场卡片图：**顺序就是卡片上的顺序**，改图之后记得同步那个文件。

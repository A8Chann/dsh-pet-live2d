# 截图

这个目录用于放插件截图。目前**空着**是刻意的：

插件自带的示例模型是 B站@氵六青 的 DS鲸鱼娘，属于第三方资产。在拿到作者的转载授权之前，
仓库只发布代码，不包含模型文件，也不包含模型的渲染截图（截图同样是该美术作品的呈现）。

拿到授权后，把截图放回这里并在根 README 中引用即可：

- `preview.png` — 桌宠与面板的整体截图（300px 宽，建议跑 `tools/browser-test/cdp-final.mjs` 生成）
- `downscale-fix.png` — 缩小时线条清晰度的前后对比

当前这些图片保存在仓库之外的 `local-assets/screenshots/`，已在 `.gitignore` 中排除。
